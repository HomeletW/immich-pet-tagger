# Public repository privacy

This repository is public. Use synthetic examples such as `user_a`, `user_b`, and `shared` in code, tests, documentation, commits, and pull-request text.

Never copy personal names, private email addresses, real account labels, local filesystem paths, LAN addresses, deployment details, or credentials from a user's environment into tracked files or GitHub discussions. Keep deployment-specific configuration outside the repository and ignored by Git.

Before publishing, inspect the staged diff and commit author/committer metadata for unintended personal information. Use the repository's configured GitHub handle and no-reply email; do not substitute the workstation's global Git identity.
